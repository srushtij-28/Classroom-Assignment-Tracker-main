# Classroom Assignment Tracker

## About

A command-line application to manage students, classroom
assignments, submission records, deadlines, and reports.

## Features

- Add and manage students
- Create and manage assignments
- Set submission deadlines
- Record student submissions
- Update submission dates
- Track submitted and pending assignments
- Identify late submissions
- Search students
- Generate assignment reports
- View classroom dashboard

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Modules
- Date Handling

## How to Run

1. Clone the repository.
2. Open the project directory.
3. Run:

   python main.py

No external packages are required.

## Data Storage

All records are stored locally in JSON files
inside the data directory.
